# Contributing to SG Air Quality

Thanks for your interest in contributing! Here's how you can help. 

## Getting Started

0. **Before** doing anything else, raise an issue, discuss it, and it'll be determined if it's something that should be developed.
1. Fork the repository
2. Clone your fork: `git clone https://github.com/stuartbreckenridge/sgairquality.git`
3. Create a branch: `git checkout -b your-feature-name`
4. Open the project in Xcode and make your changes

## Making Changes

- Keep changes focused and limited in scope
- Follow the existing code style and Swift conventions
- Add or update tests where appropriate
- Make sure all tests pass before submitting

## Submitting a Pull Request

1. Push your branch to your fork
2. Open a pull request against `main`
3. Describe what your changes made and why
4. Link any related issues
5. CodeRabbit will review your PR

## Reporting Bugs

Open an issue with a clear description of the bug, steps to reproduce it, and what you expected to happen.

## Suggesting Features

Open an issue describing the feature and why it would be useful.

## Code of Conduct

Be respectful and constructive. We're all here to make the project better.
